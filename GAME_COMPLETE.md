## 🎯 How to Play (30 Seconds)

1. **Open Project**
   - Unity Hub → Add → `unity-project` folder
   - Unity 2022.3 LTS

2. **Install Package**
   - Window → Package Manager → Install "Input System"

3. **Build Game**
   - Open `GameScene.unity`
   - Create GameObject → Add Component → `PlayableGameBuilder`
   - Right-click component → "🎮 BUILD COMPLETE PLAYABLE GAME"

4. **Play!**
   - Press ▶ button
   - WASD to move
   - Mouse to aim
   - Left-click to fire
   - Destroy all enemy tanks to win!

## 🎨 Customization Options

All configurable via Inspector on `PlayableGameBuilder`:

```csharp
numberOfEnemies: 5           // AI opponents
arenaSize: 80f              // Battlefield size
numberOfObstacles: 10       // Cover objects
matchDuration: 300f         // 5 minutes
```

### Tank Properties (TankController):
- Move speed, turn speed, acceleration
- Max health, armor values
- Weapon damage, fire rate, ammo

### AI Behavior (TankAI):
- Behavior type (Patrol, Chase, Guard, Ambush, Flee)
- Detection range, aggression level
- Patrol waypoints, reaction speed

### Camera (CameraController):
- Distance, height, damping
- Field of view, rotation speed
- Collision avoidance
